# 单选与多选自主补充（2026-10-10）

用户截图确认时间编辑问题已解决，并要求补齐“添加选项”中的自主补充。本轮沿用已提出的交互直接实现，没有再要求重复确认。

## 使用

1. 在模板编辑器选中一个单选或多选变量，点击选项区域的“添加”或“修改”。
2. 填写选项名称，例如“其他”，勾选“允许填写者自主补充”并确定。名称留空且已勾选时使用“自主补充”。每个选择变量支持一个自主补充项；已有时，在原项中修改或取消标记后再设置其他项。
3. 填写模板时选择该项，输入本次内容。单选显示为“自主补充：内容”；多选与其他勾选项按原分隔符合并。显示标记和选项名称不进入补充内容的输出，预览与复制仍使用同一份求值原文。

选项列表以“（自主补充）”标明此类选项。补充内容属于填写会话，不加入模板选项库；切换、复制会话保留本次内容与补充状态。关闭程序仍沿用已有会话不写入磁盘的策略。

## 兼容与事务

- `options` 继续使用原字符串数组；只有标记自主补充时新增可选整数 `customOptionIndex`，旧 JSON 默认全部为普通选项。非法类型、非整数和越界标记忽略，模板与选项仍保留。
- 克隆、移除和排序同步维护标记；作者取消编辑／分配失败保持旧选项及标记。模板保存仍走原原子文件替换路径。
- 补充文本与普通勾选内容分开记录，避免文本包含分隔符或恰好等于预设项时被误认。单选使用一个独立临时显示项，不修改模板，也不会反复刷新时增长列表。
- 单选等 [CBN_SELENDOK](https://learn.microsoft.com/en-us/windows/win32/controls/cbn-selendok) 后通过私有队列打开输入窗口，避免在原生下拉选择通知中嵌套模态循环；字段重建取消待处理请求，派发时核对上下文、锚点、焦点和 owner 状态。
- 多选先拥有勾选掩码的副本，再关闭鼠标捕获弹层并打开输入窗口。取消不改变原值；合并超限拒绝整次修改；内存不足不发布部分结果。由规则／引用接管的变量沿用只读行为及原优先级。
- 会话的补充快照使用可选稀疏数组，保存／恢复／复制／释放成对管理，先完整准备再发布。运行时值不借用模板对象。
