# 修复总结与目录整理（2026-10-28）

## 三个问题的原因

| 问题 | 原因 | 当前修正 |
| --- | --- | --- |
| 任务栏或托盘恢复瞬间出现黑块 | 恢复时系统可能先显示尚未完成绘制的子窗口；擦除发生在 `WM_SIZE` 和 `ShowWindow` 返回之前，事后请求重绘已经偏晚。此前部分自绘控件还只声明擦除完成而没有画入像素。 | 补全擦除绘制，并在恢复布局和全部子控件绘制完成前暂缓窗口呈现；GDI/DWM 刷新后显示，失败时保留重试路径。 |
| 分享模板后查不到数据表 | 导出只携带本机路径，接收者没有该位置的文件。 | 导出 JSON 携带数据表原始字节快照，导入时写入接收者当前数据目录并重新绑定；读取或写入失败时回滚。 |
| 滚动编辑页面误改选项 | Win32 下拉框默认响应鼠标滚轮并切换选项。 | 编辑器下拉框将滚轮交给页面滚动，点击和键盘选择保持可用。 |

前几轮黑屏修复主要检查重绘调用和隐藏窗口的 GDI 像素，未覆盖桌面合成后的恢复过渡帧，因此测试通过仍可能闪黑。本轮加入真实 Windows 桌面取帧回归：旧基线捕获到黑块，最终发布构建的四种模式、160 次恢复未捕获到大面积黑块；另有 763 项擦除绘制检查通过。完整 `make test`、默认 `make sanitize`、`make setup` 已通过。

这不等于全部机器和场景已验收：Windows 7 不支持本次使用的 cloak 接口，会回退原绘制路径；不同 DPI/显卡、人工任务栏操作、安装升级及缺失业务夹具的验证限制见[详细报告](3.5.0-restore-publication-20261028.md)。旧版仅有路径的 JSON 无法凭空恢复数据表，需要用新版重新导出分享。
