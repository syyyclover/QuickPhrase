# QuickPhrase 3.5.0 深度加固结果（2026-10-08）

这是本轮最新记录，覆盖早期报告的测试数量和产物结论。交付定位是候选版本：当前环境不能完成原生 Windows 启动、自然绘制、安装升级或泄漏验收；不宣称所有潜在问题已发现。

## 构建选择与体积

默认保留核心 O2、UI/平台/安装器 Os、LTO=0，配置指纹隔离对象，活动配置变更触发链接；不同配置必须用不同 BUILD/DIST。九尺寸 ICO、x64 展开信息、Windows 最低目标和格式化功能没有删减。普通构建使用已入库图标母图，不调用图像模型。

四种优化配置此前都通过 host 功能套件。五次交错基准的混合配置最大热点比值 1.04449，满足 ≤1.10；全 Os 和 Os+LTO 的正则分别为 O2 的约 2.94/3.21 倍，查表查询退化约 15.8%/17.2%，均拒绝。全 O2 安装包在当时为 596992 B，超 589824 B 门槛，也不选用。旧实验产物只作证据，不作交付。

当前源码的最终混合/O2 对照仍为五次交错中位数，六个热点比值为 0.98201、1.00610、0.99186、0.99258、1.05434、0.97942，满足 ≤1.10（`final-bench.json`）。基准只覆盖 host 核心，不测 UI 的 Windows 拖动性能；峰值 RSS 中位数约 32.17 MiB，不是 Windows 进程峰值。

## 保留的取舍和推迟项

完整按发生顺序的 `Ruling:` 在主 [执行记录](../.superpowers/sdd/2026-10-07-quickphrase-350-hardening/progress.md)，没有删掉未提交记录。包括：不提交/清理用户 checkout；设置和 JSON 检查扩大；无效嵌套数据拒绝；规则/选项编辑原子性；checked eval 和快照/通知预检；启动原注册表字节；固定窗口不盲缩后由滚动视口支持；精确科学计数不恢复丢失数字；读范围可失败；队列分组；检测器负控制；文案覆盖不等于视觉；声明依赖保守截断；完整表头/段落溢出；分配故障驱动可观察性；配置指纹/活动配置；低工作区视口；长表头拒绝；各类原生/泄漏/业务验收保留；多选拒绝；模态快照前置；安装器每文件事务；仅对表格/解析窗口扩展虚拟视口。

特别注意：声明但当前未激活的依赖可能保守提示截断；表文件大小和时间戳都不变时仍需手动重新加载；填写会话只在当前进程内保存；长于 127 UTF-16 单位的表头需要缩短后才能按名称绑定；安装器按文件原子替换，而非 app/uninstaller 两文件全局事务，第二个文件失败可留下完整新 app 与旧卸载器，需要重试。

保留旧 UTF-16 单位索引，但边界不能拆开代理对：落在低半部的起点向前对齐，结束点截短；结果可能比要求的单位范围短。安装器暂存名复用既有 native formatter，超限或无结束符时必须在创建临时文件之前拒绝。代码审查和流程记录不会代替这两项的真实系统边界验收。

最终审查的两项 Minor 按流程推迟：README 仍有“按名称引用”的旧文档措辞；设置部分回滚提示没有细分具体失败位（已诚实报告部分失败，没有宣称全部恢复）。
