# 3.5.0 显示专项修复记录

以下为上一轮显示补修的历史记录。2026-10-08 已增加自然/参考屏幕对照诊断、布局损坏区域处理、绘制降级、窄编辑器及固定窗口视口，最新状态见 [加固报告](3.5.0-hardening-results.md)。当前环境仍不能运行真实 Windows 视觉断言，不能把此前“强制重画后检查”当自然绘制通过。

## 本轮目标与基线

用户提供了真实 Windows 截图：查表解析的复选框和说明被裁切，中部有大量空白；还反馈模板编辑器拉伸时文字闪烁，以及 EXE 文件图标未更新。此前仅用源代码几何检查不能验证这些实际显示问题。

已复现的自动化基线：旧规则布局没有按类型收紧；同尺寸编辑器重复布局产生 54 次显示调用、4 次列宽设置和一次滚动信息设置。当前发布 EXE 的九种尺寸图标数据与新 ICO 逐像素一致，尚不能据此推断用户看到旧图标的原因。

## 实现

- 规则布局提取为纯像素计算，实际字体、摘要/说明高度由 Win32 测量后传入。仅显示当前规则适用的行；类型切换收紧高度，窗口支持缩放。
- “逐段处理”复选框改用短标题，说明单独换行；查表摘要为只读多行可选择、可滚动控件；操作说明不使用省略显示。
- 编辑器可见性更新与几何布局分开，跳过相同列宽、滚动信息和重复尺寸消息；撤掉布局中的强制即时重绘。属性背景和普通文字标签局部缓冲绘制，不使用整窗 WS_EX_COMPOSITED。
- 编辑器长说明、时间示例及复选框使用实际字体测量行高；空模板也为模板级控制保留可滚动范围。相同类型的规则说明和数据表长路径改为完整可访问文本。
- 新增 PE 图标资源检查，逐尺寸比较原始图像负载；安装器内嵌程序和卸载器必须与构建文件一致。启动/安装完成通知 Shell 更新特定文件。

## 图标本机诊断

`dist/QuickPhrase-icon-check.exe` 不运行目标 EXE，不读取模板内容。示例：

```bat
QuickPhrase-icon-check.exe "D:\实际目录\QuickPhrase.exe"
QuickPhrase-icon-check.exe "D:\实际目录\QuickPhrase.exe" --refresh
```

输出实际路径、SHA-256、大小图标的 Shell/直接提取渲染对比，并把 BMP 预览保存到新建的临时目录。默认只读；`--refresh` 仅发送该文件的 Shell 更新通知，不删除全局缓存。先核对文件和校验和，再定位显示链路。

## 验收状态

- `make test`：10 个 C 测试程序、16 个 Python 检查通过（`build/display-test-final.log`）。规则布局覆盖 60 组 DPI/宽度/类型，编辑器重复布局覆盖 48 组，查表窗口几何覆盖 68 组。
- `make setup`、`make icon-check` 与真实 Win32 测试程序交叉编译通过；构建检查内嵌 manifest、九种尺寸图标负载及安装器内嵌文件一致性（`build/display-final-build.log`）。
- 初次编译时挂载文件的修改时间短暂领先系统时钟约 2 秒，make 提示时钟偏差；时间恢复后重新执行构建确认（`build/display-build-confirm.log`）并独立检查 dist 中实际文件资源。三份交付文件通过 `dist/QuickPhrase-3.5.0.sha256` 校验。
- 默认 `make sanitize` 未通过：LeakSanitizer 明确报当前 ptrace 沙箱不受支持（`build/display-sanitize.log`）。另行以 `ASAN_OPTIONS=detect_leaks=0 make sanitize` 完成 ASan/UBSan 检查（`build/display-asan-ubsan-final.log`），这不代表泄漏检查通过。
- `make win32-test` 未能执行界面断言：Wine 的服务套接字绑定被沙箱拒绝（`build/display-native.log`）。测试程序已补充真实 DPI 字体、折行说明和多行复选框高度、连续拖动与文字擦除像素检查；图标工具 `--self-test` 使用两种不同图标检查 GDI 批处理输出，但这些原生断言尚未在 Windows 执行。
- 独立复核指出图标 DIB 读取缺少 GDI 同步、DPI 测试未缩放实际字体，两项已修正；诊断输出也统一为宽字符，避免中文路径因混用输出流丢失。

真实 Windows 的拖动录像、字体效果和资源管理器显示仍需实际系统验证；不会将模拟几何、消息计数或 PE 资源检查标成这些项目已通过。特别是用户看到旧 EXE 图标的原因仍待本机路径/校验和/Shell 对比定位。保留现有工作区和分支，无自动提交或推送。
