# QuickPhrase 普通文本与表格双输出设计

## 背景与目标

现有批量渲染能力可以生成带真实制表符的内容，但表格行只能伪装成模板末尾的固定片段。为避免原始输入和派生变量重复输出，示例模板又把多数片段设为“隐藏”和“不计入输出”。结果是功能难以发现：普通预览可能为空，用户也无法明确选择或复制表格格式。

本次改动把“普通文本”和“表格”提升为同一模板的两种正式输出格式：

1. 普通文本继续按模板片段顺序生成，兼容所有旧模板。
2. 模板可另外配置一个表格格式串，以真实 Tab 分列、换行分行。
3. 主界面明确切换两种预览，一键复制当前格式。
4. 原始输入变量是否显示、片段是否进入普通文本，仍由现有“隐藏”和“不计入输出”分别控制；表格格式不再依赖这两个开关拼凑。

## 数据模型与 JSON

`Template` 新增两个可选属性：

- `tableOutputEnabled`：是否为该模板启用表格输出。
- `tableOutputFormat`：表格格式串，例如 `{资源池}\t{地区}\t{涉及设备}`。

两项均为模板级配置。格式串沿用现有固定片段的占位符和转义语义：

- `{变量名}` 在求值后替换为该变量当前值。
- `\t` 生成一个真实 U+0009 制表符。
- `\n` 生成换行。
- 其他固定字词原样保留。

旧 JSON 没有这两个字段时，表格输出关闭，行为与当前版本一致。保存时仅在启用或内容非空时写入新增字段。导入、导出、克隆模板时完整保留两项配置。

表格格式只定义输出排列，不改变输入值、规则、引用、默认值及条件求值。格式中的未知变量保持现有占位符处理语义，并由模板体检报告。

## 渲染语义

引擎提供两个相互独立的入口：

- 普通文本渲染：继续按照片段顺序和 `noOutput` 生成结果。
- 表格渲染：对 `tableOutputFormat` 展开转义和变量占位符，不按片段顺序追加内容，也不受片段 `noOutput` 限制。

这是必要的正交关系：`noOutput` 只表示“该片段不直接进入普通文本”，不能阻止变量被表格格式引用。

批量模式对两种格式都有效。选择普通文本时，每个非空源段独立求值并生成一份普通文本；选择表格时，每个非空源段独立求值并生成一行表格。各份结果用换行连接，渲染结束后恢复完整源输入。

若模板没有启用表格输出，表格格式为空或当前没有模板，则主界面只提供普通文本模式。表格模式求值为空时，预览为空并沿用“当前口径为空”的复制提示，不回退到普通文本，避免复制错误格式。

## 模板编辑器

模板头部的批量设置附近增加“启用表格输出”。启用后显示一个多行“表格格式”编辑框和简短提示：`{变量名}` 插入变量，`\t` 分列，`\n` 换行。

格式编辑框允许直接输入和粘贴格式。为避免用户手工记忆变量名，旁边提供“插入变量”下拉或按钮：选择变量后在当前光标处插入 `{变量名}`。首版不增加复杂的可视化列设计器，保持通用且可编辑。

编辑表格开关、格式内容或插入变量后，默认值预览立即刷新。编辑器预览区也提供“普通文本 / 表格”切换；表格未启用时只能预览普通文本。

保存前体检新增以下项目：

- 已启用表格输出但格式为空。
- 表格格式引用不存在或名称不唯一的变量。
- 表格格式没有实际 Tab（允许用户确认保存，但提示它不会形成多列）。

现有规则、引用和批量源体检继续保留。

## 主界面

“口径预览”标题行增加两个互斥选项：`普通文本`、`表格`。

- 默认选择普通文本，确保导入模板后粘贴原始口径即可看到普通输出。
- 模板未启用表格格式时，隐藏或禁用“表格”选项。
- 切换后立即重新渲染预览，不修改任何输入值。
- 选择表格时，提示文字说明“复制后可直接粘贴到 Excel / 在线表格”。
- 原“一键复制”和 `Ctrl+Enter` 保留，复制当前预览模式；按钮文字可显示为“一键复制文本”或“一键复制表格”，成功提示也明确对应格式。
- 切换模板时回到普通文本，避免从一个支持表格的模板切到另一个模板后仍处于不可用状态。

预览框继续使用只读多行文本控件。Tab 在文本框中的视觉宽度不代表单元格边界，但剪贴板中必须保留真实 U+0009；不使用多个空格模拟列分隔。

## 交付模板调整

`QuickPhrase-模板.json` 中“巡检”模板调整如下：

- “巡检数据”保持可见且参与普通文本输出，导入后用户能直接粘贴并看到内容。
- 仅由规则生成的中间变量继续隐藏，并可继续设置为不计入普通文本。
- 删除依靠末尾条件固定片段生成表格行的做法。
- 将原表格行表达式迁移到 `tableOutputFormat`，启用表格输出。
- 普通文本模式呈现未经改写的输入及模板明确配置的普通文字；表格模式呈现按列重排的结果。

`data.json` 中相应的“巡检”模板同步迁移，避免内置数据和交付文件行为不一致。其他模板不自动启用表格输出。

## 测试与验收

### 引擎与存储

- 普通文本和表格格式对同一组变量产生各自独立的结果。
- 表格格式中的 `\t` 是实际 Tab，`\n` 是实际换行。
- 隐藏或 `noOutput` 的变量仍可被表格格式引用。
- 单段及多段批量输入在两种模式下均逐段重新求值，无值残留。
- 新字段 JSON 往返不丢失；旧模板读取后行为不变。
- 克隆模板保留双输出配置。
- 新增体检项正确报告空格式、未知/歧义变量和无 Tab 格式。

### UI

- 导入交付模板后，“巡检数据”输入框可见。
- 粘贴未处理口径后，普通文本预览立即出现内容。
- 切到表格模式后立即显示制表符分列结果；切回普通文本不丢输入。
- “一键复制”和 `Ctrl+Enter` 均复制当前模式，空结果不复制旧内容。
- 将表格结果粘贴到 Excel 或在线表格时，各元素进入相邻单元格，多段输入每段占一行。
- 编辑器修改表格格式后预览实时同步；预览分隔条仍无错位。
- 保存模板时原有逻辑体检与新增表格体检均可触发。

## 非目标

- 不增加 Excel 文件生成或 Office 依赖。
- 不引入脚本语言、正则表达式或新的 UI 技术栈。
- 不自动猜测列定义；列顺序和常量由模板作者明确配置。
- 不改变现有隐藏、默认值、条件规则和引用的基本语义。
