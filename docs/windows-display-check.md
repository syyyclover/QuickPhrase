# Windows 自然绘制验收

当前 Linux/Wine 的环境失败不能替代 Windows 验收。使用新建的 Windows 测试账号；测试会写入该账号的测试设置，已有 QuickPhrase 配置、数据或窗口时拒绝运行。不要临时移动真实用户数据来绕过保护。

构建 `make build/test_win32.exe`，在可交互且无遮挡的桌面运行：

```bat
test_win32.exe --artifacts D:\QuickPhrase-test-artifacts
```

参数目录下创建唯一子目录，不覆盖已有结果。程序先用故意残留旧像素的探针检查检测器，再调整真实窗口并捕获实际屏幕客户区；自然图采集之前不强制整窗重画。随后完整重绘同一几何作为参考；不使用会主动调用绘制的 PrintWindow。失败时保存 natural/reference BMP 和控制台差异像素数。窗口遮挡、屏幕不可用或资源不足返回未完整验收状态（退出码 3），不是通过。

自动 DPI 案例使用实际 GDI 字体、分别模拟 96/120/144/192 布局输入；不能代替真正更改 Windows 缩放后重启应用的测试。人工分别在 100%/125%/150%/200% 下检查：窗口外框单改宽/单改高、缩小放大、预览分隔条、属性滚动、最大化恢复、深浅主题、长说明、窄窗口页签、Tab/焦点滚入、复制选择、取消、保存失败、EXE 图标与安装升级。特别测试 1366×768 工作区及任务栏扣减区域。

使用脱敏的截图对应模板进一步回归；夹具未提供时记录缺失，不把合成数据当真实业务验收。检测器、截图与手动结果分别记录到最终报告。

本轮还应人工核对：表格/解析规则在小工作区的虚拟画布、缩放后滚动范围和 Tab 显露关闭/确认按钮；长表头拒绝时恢复原映射；多选超限时只回退本次勾选；文本/表格切换及内存不足后显示/选择复制/一键复制一致；确认编辑后填写快照仍保留；覆盖升级短写/刷新/关闭/替换失败保留旧 EXE（使用可恢复的测试目录及文件副本，不对生产安装注入故障）。
