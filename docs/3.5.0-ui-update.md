# 3.5.0 窗口绘制与逐段填写更新（2026-10-09）

本次是在现有 3.5.0 工作区上的增量修改，保留用户已有重构、资料和旧产物记录，没有提交、合并或推送。当前产物和验证以本文为准；之前的 hardening 报告保留历史结果。

## 行为与实现

- 主窗口最小化时不再进行零尺寸布局，保留填写区和预览的有效尺寸。还原、最大化和分隔条拖动在嵌套布局完成后处理父窗口及全部子控件的待绘制区域；填写区背景改由带缓冲的 `WM_PAINT` 绘制，缓冲失败沿用直接绘制回退。
- 编辑器预览分隔条拖动在属性区和预览摆位完成后统一处理待绘制区域，避免仅刷新分隔线、让子控件留到下一次消息循环。沿用配对私有布局队列；纯位移保留像素，尺寸变化仍用 `SWP_NOCOPYBITS`。
- 解析规则的“逐段处理”新增“换行填写／连续填写”及分隔符。连续填写只拼接命中的段，分隔符留空直接连接，保留分隔符中的空格；普通解析与逐段查表的所有输出目标共用这套选择。输入仍按 LF/CRLF 分段。
- JSON 新增可选 `paragraphInline`、`paragraphSeparator`；缺少字段仍默认换行。克隆保留设置，关闭连续填写时仍保存非空分隔符；取消编辑沿用工作副本语义。没有更改规则优先级或批量整模板输出。
- 表格格式编辑新增“插入单元格分隔符”，在光标／选区处插入字面量 `\t`。先插入 `{test}` 再点击按钮可得到 `{test}\t`。变量和分隔符插入共用容量预检，长度不足时拒绝整次插入，保留原文与选区；关闭表格输出时禁用按钮。

绘制策略依据 [SetWindowPos 的像素保留规则](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos) 和 [RedrawWindow 的子窗口及同步绘制规则](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-redrawwindow)。这些 API 规则和本地回归不能证明用户机器上的瞬时黑闪已经消失。
