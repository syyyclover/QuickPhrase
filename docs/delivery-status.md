# 当前交付核对（2026-10-10）

`dist` 只保留一套当前产物：`QuickPhrase.exe`、`QuickPhrase-3.5.0-setup.exe`、`SHA256SUMS`。程序与 `build/QuickPhrase.exe` 逐字节相同；安装包此前已通过内嵌程序／卸载器、manifest、图标与体积核对，本次文件及校验和再次通过。

旧产物、旧校验清单、诊断工具和原独立交付目录保留在 `build/release-archive/dist-before-consolidation-20261010-0x_d53_f`。未删除用户原件，没有提交／推送。

不能断定未看到成效是缓存或构建造成。已查明两个错版风险：整理之前的根目录程序比独立目录程序旧；全局单实例锁可能使新 EXE 退出并唤起旧进程。退出托盘旧进程、核对实际运行路径，再运行最新版是必要的对照。主窗口偶发黑闪尚未通过 Windows 视觉验收。

当前版本仍把 `settings.json` 保存到 `%APPDATA%\QuickPhrase`，默认模板同目录；配置隔离尚未实施。已提出的待确认方案是 EXE 所在目录保存设置／模板、按安装路径隔离单实例、取消外部数据目录、卸载可保留本目录 JSON，新安装不自动读取旧 APPDATA。另一迁移选项是首次复制旧配置到各自目录后独立读写；旧数据均保留。

时间修改已获用户确认；单选／多选自主补充也已实施，见 [当前记录](3.5.0-custom-choice.md)。配置目录隔离和原生黑闪验收仍未完成。
