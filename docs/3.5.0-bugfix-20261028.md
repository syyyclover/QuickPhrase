## 修改

- 主窗口从最小化还原、最大化状态切换时，显式失效并立即绘制完整客户区和子控件；从托盘显示时也执行完整重绘，覆盖几何完全未变、没有产生新无效区域的情况。普通拖动缩放继续使用原有增量绘制。回归能证明原代码缺少这些重绘请求，不能证明所有 DWM 动画期间的黑屏均已消失，仍需原生视觉复测。
- 导出的 JSON 在 `dataTables` 条目中新增可选 `contentHex`，携带数据表原始字节；路径只保留文件名。普通 `data.json` 保存仍然只存表引用。导入时先把快照写到当前数据目录下生成的新文件，再提交模型，保留编码、分隔符、表头和表 ID。文件以独占创建方式写入，不使用分享文件提供的目录，不覆盖现有文件；准备失败时回收本次已创建的文件并保留原模型。导出读取失败或 JSON 超出读取器 256 MiB 上限时拒绝写入，保留原导出文件。
- 模板编辑器的属性、时间格式、分组和批量来源下拉框不再通过鼠标滚轮切换值；滚轮交给属性区滚动。键盘和点击选择保持原有行为，焦点显露仍只应用于属性区内的控件。

旧版仅含路径的 JSON 仍可按原规则导入，但其中不存在的数据表内容无法从路径还原。跨电脑分享请使用本轮程序重新导出，接收方也须使用支持快照的新程序。导入得到的是导出时的快照；重复导入生成独立文件，旧快照目前不自动删除。
