# examples —— 验收用的原始输入

这里是从真实告警里摘出来的样例输入，用来验证「巡检」这类批量模板的表格输出：

| 文件 | 说明 |
| --- | --- |
| `示例完整.txt` | 六行完整的原始告警，配合 `QuickPhrase-模板.json` 里的「巡检」模板使用：粘进「巡检数据」变量，切到表格预览，应当每行一行、列对齐 |
| `示例.txt` | 同一批告警的节选，随手试规则时用 |
| `示例.png` | 早期版本主界面的截图 |

## 怎么用

1. 主界面「文件 → 导入」，选仓库根目录的 `QuickPhrase-模板.json`；
2. 左树选中「巡检」；
3. 把 `示例完整.txt` 的内容整段粘进「巡检数据」输入框；
4. 预览切到「表格」——每行一行，没取到值的格子会标红「未匹配」；
5. `Ctrl+Enter` 复制，直接粘到 Excel / 在线表格。

## 说明

这些是**本机验收用的样例**，不参与编译，也不会被打进安装包；`.gitignore` 里
按「临时文件」忽略，所以不进版本库。软件本体与安装包只内置两个测试模板
（`软件版本发布说明口径` 与 `复杂示例 · 违规处置通报`），不含任何业务模板。
